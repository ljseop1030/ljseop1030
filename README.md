## 🚀 Highlighted Projects

* **[Investigation Desk](https://github.com/ljseop1030/investigation-desk)** | solo · [live demo](https://investigation-desk.pages.dev/)
  * Messenger-style web game where LLM-driven NPCs answer the player's requests (React, Cloudflare Functions, Gemini API)
  * Checks every record an NPC claims to hand over against game data, so hallucinated hand-offs never change game state
  * Time-skipping integration tests and CI/CD with GitHub Actions
* **[Pintrip](https://github.com/ljseop1030/pintrip)** | LLM extraction lead
  * Android app that turns places shared from social media into pins on a group trip map (Kotlin, Gemini, Kakao API)

  * Social reading app for daily English poems; REST endpoints with Jest tests and OpenAPI docs, launched Nov 2026 (Node.js, Express)

  * Ground-truth input and per-session MAE to evaluate fill-level and purity estimates; admin trace API (Python, FastAPI)
